# RobinHood Web

Official landing page for [RobinHood](https://github.com/Faroffcode/robinHood), an independent open-source YouTube Music client for Android.

## Stack

- Static HTML, CSS and JavaScript
- No build step
- Responsive and mobile-first
- GitHub Pages deployment through GitHub Actions

## Local preview

Open `index.html` directly, or serve the folder with any static HTTP server.

## GitHub Pages

Every push to `main` triggers `.github/workflows/deploy.yml` and publishes the site with GitHub Pages.

In the repository settings, make sure **Pages → Source** is set to **GitHub Actions** if GitHub asks for a source selection.
